# Playwright with Claude Resources

## Knowledge

- [Playwright MCP README (microsoft/playwright-mcp)](https://github.com/microsoft/playwright-mcp)
  Official source for flags, capability sets (`--caps`), the tool list and security notes. Use for: any config or tool-name question.
- [Playwright docs: Getting started with MCP](https://playwright.dev/docs/getting-started-mcp)
  Official install and first-prompt guide, snapshots, profiles, idle timeout. Use for: setup and core concepts.
- [Claude Code docs: Connect Claude Code to tools via MCP](https://code.claude.com/docs/en/mcp)
  `claude mcp add`, scopes, `.mcp.json`, `mcp__<server>__<tool>` names. Use for: adding, scoping and permissioning servers.

## Wisdom (Communities)

- [playwright-mcp issue tracker](https://github.com/microsoft/playwright-mcp/issues)
  Maintainer-run tracker for the MCP server. Use for: bugs and behaviour questions. Not a learner community; see Gaps.

## Gaps
- No vetted community specific to Claude-driven browser automation yet.
- Permission rule syntax for `mcp__*` tools not yet read from the Claude Code permissions docs.
