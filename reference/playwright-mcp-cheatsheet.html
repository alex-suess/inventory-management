Playwright MCP cheat sheet

Sources: README, docs, Claude Code MCP docs. Version note: this repo pins 0.0.37.

The loop

browser_navigate -> browser_snapshot -> browser_click / type / fill_form -> browser_snapshot

Add the server to Claude Code

claude mcp add playwright -- npx @playwright/mcp@latest
claude mcp list        # health
/mcp                   # inside a session

Scopes: local (default, ~/.claude.json), project (.mcp.json, shared), user (all projects). Tool names look like mcp__playwright__browser_click.

Flags

FlagEffect
--headlessNo visible window (default is headed)
--browserchrome, firefox, webkit, msedge
--isolatedIn-memory profile; state lost on close
--user-data-dirCustom persistent profile; one browser per profile at a time
--storage-stateLoad cookies and local storage into an isolated session
--capsExtra tools: vision, pdf, devtools, plus config, network, storage, testing
--allowed-origins / --blocked-originsRestrict sites

Security

The README states Playwright MCP is not a security boundary. browser_run_code_unsafe runs arbitrary JavaScript in the server process.
